# Wezterm Config
For Windows 11 and WSL2 Ubuntu

## Setup
```bash
git clone repo # clone repo
mv repo /mnt/c/Users/saiha/.config/. # put in spot
mv /mnt/c/Users/saiha/.config/repo /mnt/c/Users/saiha/.config/wezterm # rename to wezterm
```
